# 反转之城 · 高中互动课

在一座日光充足的城市里，和阿岚、导航机器人一起修复会产生矛盾结论的数据装置。课程把辛普森悖论、条件概率、加权平均、因果图和标准化串成 40 幕可以操作的任务。

**本项目只在本地运行。没有发布网址、云数据库、账号系统或联网聊天接口，不上传学生回答。原有项目未作修改。**

## 立即开始

已交付可运行成品 **dist-offline/**，图片和数学字体都已包含。运行这份成品不需要安装项目依赖，只需要本机已有 **Node.js 22.13 或更新版本**。本次测试使用 Node.js 24.15.0。

### macOS

在访达中打开本文件所在文件夹，双击 **启动课程.command**。保持弹出的终端窗口开启，然后在浏览器访问：

**[http://127.0.0.1:3004/](http://127.0.0.1:3004/)**

如果系统不允许直接打开脚本，可在此目录的终端运行：

~~~sh
npm start
~~~

### Windows

复制完整项目文件夹后，双击 **启动课程.bat**，再访问上面的地址。Windows 启动脚本已提供，但本次未在 Windows 设备上实测。

### 停止或更换端口

在运行课程的终端按 Ctrl+C 即可停止。页面不是直接双击 index.html 打开的离线文档，需要这个本地 HTTP 服务。

若端口已被占用，先确认是不是本课已在运行。不要结束不相关项目的服务。在 macOS/Linux 可以改用：

~~~sh
REVERSAL_CITY_PORT=3014 npm start
~~~

然后访问 http://127.0.0.1:3014/。本地服务只监听本机，不向局域网或互联网开放。

**存档按浏览器和网站地址隔离。** localhost 与 127.0.0.1、不同端口、无痕窗口是不同的存档环境；上课时请固定使用同一地址。

## 三种使用方式

| 模式 | 使用方式 | 存档关系 |
| --- | --- | --- |
| 学生探索 | 完成必要的观察、计算、连接或判断后解锁下一幕；城市地图与快速导航栏显示地点、工具和进度 | 自动保存探索进度、初始观点、操作和最终表达 |
| 教师演示 | 自由选择 40 幕；展开参考解释、三级提示、暂停动画、重置当前实验；可开启投影大字 | 教师场景与学生任务数据分别保存 |
| 独立高考 | 随时进入五问共 17 分的答卷；提交前不展示参考答案；提交后看实际得分点，再修改重提 | 独立答卷，不继承探索中的第 27—31 幕答案 |

初始观点没有对错分；错误允许重试，不扣生命值、不设强制倒计时或排行榜。第 37 幕的开放表达完整保存，不做关键词“语义评分”。

40 幕另按思考阶段分成五个部分（数据现场、从数字到现实、第一件因果工具、高考迁移、因果图不是万能答案）。每部分首幕有一张开场卡说明它为什么存在；顶部“正在追问”显示当前阶段的核心问题；每幕完成后给出指向下一幕的交接语。

数据范围条下方是快速导航栏：40 个幕次按六个地点分组，标出已完成、当前和未解锁，点击即可切换（沿用与城市地图相同的解锁门槛）。窄屏收成“第 NN / 40 幕”按钮展开。

默认静音。设置中可开启反馈音、减少动态、跳过场景动画和投影大字；跳过动画不会代替学习任务。设置底部的“重置全局进度”需要选择范围：只清空当前模式，或清空全部学习记录；两者都保留显示与声音偏好。拖动连接、排序和分类均有点击、下拉选择或键盘操作替代。

## 城市里的六个地点

| 地点 | 幕次 | 核心机关 |
| --- | --- | --- |
| 反转广场 | 01—04 | 初始判断、同幕完整反转、证据分类、原始计数、总体与分层 |
| 条件车站 | 05—12 | 1725→483→108→89 条件闸门、概率计算、构成滑杆、公式组合 |
| 因果工坊 | 13—18 | 关联与因果问题分类、模拟审核情境、变量和目标箭头 |
| 双世界实验室 | 19—26 | 反转重现、混杂路径、控制变量、共享人群、函数与标准化 |
| 推理塔 | 27—31 | 五问递进综合题，与独立高考使用同一套评分逻辑 |
| 观测天台 | 32—40 | 遗漏变量、随机分配、混杂与中介、迁移案例、开放反思和知识图谱 |

开发结构为 Sites 的 React＋TypeScript 项目，保留原始框架构建；另用同一套 React 组件生成不需要云服务的本地成品。未注册站点、部署或绑定数据库。

## 继续开发

首次安装开发依赖需要网络。仅运行已交付成品不需要执行这一步。

~~~sh
npm ci
npm run dev
~~~

开发服务器也使用 3004 端口，不要与成品服务同时占用同一端口。停止原服务后再切换。

~~~sh
npm run check       # TypeScript、ESLint、39 项自动化测试
npm run build       # 框架构建 + 本地成品构建
npm start           # 运行 dist-offline 成品
~~~

另开终端检查运行资源：

~~~sh
npm run test:built  # 需要 npm start 已启动；只检查本机 URL
~~~

图片、字体、JavaScript 和 CSS 都从本机加载。资料来源链接只有在主动点击时才需要联网。保存机制使用带版本号的本地键 reversal-city:course:v1；不会读取旧项目存档。若浏览器禁用存储或空间不足，课程会提示并继续以当前内存状态运行，但刷新后可能丢失这一轮进度。
