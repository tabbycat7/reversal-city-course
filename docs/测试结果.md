## 教师与设置

- 教师从学生中途进度直接跳到第 33 幕，暂停、参考和重置自己的实验后，学生原进度及连线仍在。
- 第 6 幕教师直达时有当前符号解释；计算完成前不泄露表格答案列。
- 三级提示逐层出现，重置有确认，可取消。
- 教师暂停时装饰动画暂停；返回学生后不继续错误地沿用教师暂停样式。
- 默认静音；减少动态设置会恢复，但不会绕过学习动作。
- 图连接、排序与分类均有原生控件替代；页面按钮含可访问名称。

本次检查了实际键盘和替代操作，但没有把它宣称为完整的 WCAG 认证或所有屏幕阅读器兼容认证。

## 成品与运行资源

本地成品由同一套 React 课程组件构建，并非演示截图或静态替代品。内置服务器只监听 127.0.0.1，依赖 Node 内置模块，不需要运行时安装 React、云服务、数据库或账号。

资源检查逐一验证全部文件的 HTTP 状态、大小、正确的本地引用和 nosniff 头。成品包含 59 个数学字体文件，页面实际加载 KaTeX_Main 与 KaTeX_Math，公式同时含 MathML。

构建仍有一个非阻塞提示：压缩后的单个主 JavaScript 文件约 872 kB，gzip 约 279 kB，超过 Vite 默认 500 kB 的提示阈值。该提示不影响本地运行；后续若用于网络发布，可再按章节拆包。本次没有为消除提示而隐藏警告，也没有执行发布。
